# AI API Integration with Express.js

A modular RESTful API middleware service built with Node.js and Express.js that connects client applications to Google Gemini AI, capable of processing multiple input formats and returning structured AI-generated responses.

Built as part of the **Hacktiv8 AI Productivity and AI API Integration for Developers** program (August 2025).

---

## What It Does

- Accepts multi-format inputs: **text, images, documents, and audio**
- Routes requests to **Google Gemini API** and returns structured text-based responses
- Built with a **modular backend architecture** — endpoints, logic, and API integration are separated for readability and easy extension

---

## Tech Stack

| Layer | Technology |
|---|---|
| Runtime | Node.js |
| Framework | Express.js |
| External API | Google Gemini API |
| Architecture | Modular RESTful API |

---

## Key Features

- **Multi-format input handling** — single API capable of processing different content types
- **Modular routing** — each endpoint is independently structured, making it straightforward to add or modify routes
- **Structured response formatting** — consistent output regardless of input type

---

## What I Learned

- How to design a backend as a middleware layer between client and a third-party AI API
- Practical modular architecture patterns for Express.js applications
- Handling varied input types within a unified API structure
- Working with Google Gemini API responses and formatting them for client consumption
